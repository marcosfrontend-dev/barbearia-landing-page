# 💈 Barbearia Navalha & Estilo — Landing Page com Agendamento

Uma landing page moderna, de alta conversão e totalmente responsiva, desenvolvida para automação de agendamentos via WhatsApp de uma barbearia.

---

## 🚀 Funcionalidades

- **Design Responsivo (Mobile-First):** Layout limpo em *Dark Theme*, otimizado para celulares, tablets e desktops com menu hambúrguer interativo.
- **Validação de Data e Hora em Tempo Real:** 
  - Impede a seleção de datas passadas no calendário.
  - Bloqueia horários que já passaram se o cliente escolher o dia atual.
- **Agendamento via WhatsApp:** Captura os dados do formulário modal, formata o pedido e redireciona o cliente para o chat do WhatsApp com a mensagem estruturada.
- **Navegação Suave (*Smooth Scroll*):** Rolagem fluida entre as seções de Serviços, Sobre e Contato.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido do zero sem o uso de frameworks externos para garantir máxima performance e leveza:

- **HTML5:** Estruturação semântica da aplicação.
- **CSS3:** Estilização com variáveis CSS, Flexbox, CSS Grid e *Media Queries*.
- **JavaScript (ES6+):** Manipulação da DOM, validações de data/hora nativas e integração com API `wa.me`.
